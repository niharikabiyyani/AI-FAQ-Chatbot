# 📚 AI FAQ Chatbot

An AI-powered FAQ chatbot built using Python, TF-IDF, cosine similarity, and Gradio.

## 🚀 Features

- Answers frequently asked AI and ML questions
- Uses TF-IDF for text representation
- Uses cosine similarity to find the closest question
- Interactive Gradio interface
- Beginner-friendly FAQ knowledge base

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Gradio
- TF-IDF
- Cosine Similarity
